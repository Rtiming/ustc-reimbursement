# 候选安全审查记录

[中文](安全审查_20261025.md) | [English](en/security-review.md)

范围：0.5候选源码、锁定依赖、安装状态目录、CLI/JSON/MCP配置、材料XML读取、分发成员及公开Git历史。日期：2026-10-25。未操作用户Windows现场、未登录财务、未填写验证码、未提交或批准真实单据；本记录不是现场验收或无漏洞保证。

## 发现与修复

| 项目 | 发现 | 候选修复与验证点 |
| --- | --- | --- |
| Python运行时 | 旧便携Python3.12.13实际使用Expat2.6.3，未覆盖后续安全修补 | 冻结uv0.13.5/Python3.12.15；Mac新运行时回读Expat2.9.0。XML入口拒绝低于2.8.5的解析器 |
| Pillow | 旧锁定12.2.0命中上游已知安全公告 | 锁定13.0.0；重新验证图片/PDF/OCR与三系统安装 |
| OpenTelemetry API | 1.45.0命中CVE-2026-114603 | 锁定1.45.1；默认stdio不公开HTTP，但仍修补依赖 |
| Office/OFD XML | 多处标准解析入口；部分声明检查只匹配ASCII字节，可遗漏UTF-16 | 统一safe_xml/defusedxml，拒绝实体和外部资源，限制大小/深度/节点，ZIP成员先限额再读取 |
| 归档helper下游 | vendor验SHA后普通加载器可能采用pyc或再次读取变化的源码 | 对刚验证的同一字节compile/exec；以时间/大小匹配的异内容pyc进行负向回归 |
| 安装目录 | `.local`检查原在Python安装阶段，bootstrap可能先跟随外部链接 | 下载、写入及--check执行前拒绝越界链接/Windows重解析点；正常内部Python链接保留 |

上轮已修并复核的授权撤销CAS、同路径桥状态保护及跨用户安装任务清理继续保留回归。没有把候选规则、人工授权标志或模拟结果当成真实财务证据。

## 扫描解读

依赖审计通过PyPI的已知漏洞数据检查完整锁文件，结果以相应提交的CI为准。旧公告包含重复ID/别名，因此不把原始条目数当作独立漏洞数。修补依赖版本不自动更新既有安装或旧Release。

Bandit用于定位Python静态风险点，不能直接裁决漏洞。XML类告警由统一解析边界处理；SQL构造使用固定表/列/查询片段，用户值单独绑定；共享helper的exec仅执行已验SHA的固定字节；Mac认证socket使用mkdtemp及0700/0600权限。subprocess调用、合成assert及空密码默认参数等低级别提示保留审查理由，不通过全局忽略制造“零告警”。

公开树和全部公开历史使用gitleaks --redact扫描。仅精确文件/精确值的扩展身份公开RSA密钥例外，不忽略任意同名key。分发采用明确允许清单，不包含cases、私人规范、.local、账号会话或凭据。

## 配置与信任边界

源码、运行时和本机配置属于可信安装边界；材料可以是不可信输入。不能把“SHA一致”解释成操作者任意指定的程序安全，也不能声称能防御本机管理员篡改。没有公网MCP端口，不支持把当前桌面财务适配器直接当作多用户网络服务。

只读/预览与执行分开，execute须为布尔值。配置版本及权限变化阻止旧工作流推进。未知金融结果保留原任务，安装器不清理历史业务证据。短信验证码由本人输入；显示窗口需要明确选择。

剩余边界：Windows真实接线、登录、验证码后接续、实际批准和实际系统导出仍待用户恢复现场验收；旧0.4预发行安装不因本候选修复而获得新资格。当前更新留在草稿分支，不发布新版。

方法依据：[pip-audit](https://github.com/pypa/pip-audit)、[Python XML安全说明](https://docs.python.org/3/library/xml.html#xml-vulnerabilities)、[Pillow 13.0发布说明](https://pillow.readthedocs.io/en/stable/releasenotes/13.0.0.html)、[OpenTelemetry 1.45.1](https://github.com/open-telemetry/opentelemetry-python/releases/tag/v1.45.1)。
