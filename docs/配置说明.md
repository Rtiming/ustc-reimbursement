# 配置说明

[中文](配置说明.md) | [English](en/configuration.md)

0.5候选版的配置和文档以本分支为准。Windows真实财务验收仍暂缓；隔离安装、合成资料和接口检查不等于真实批准通过。语言只控制帮助文档，不翻译财务字段、不改变权限或默认值。

## 一次性选择

| 配置 | 入口 | 默认及限制 |
| --- | --- | --- |
| 资料根 | 安装器`--data-dir` | 默认工具下materials；选择专用目录，不授权整个用户目录或磁盘 |
| 专项ID/名称 | `--profile-id`、`--title` | my_project/我的报销项目；新规则为空，未确认 |
| 材料场景 | `--mode` | student_activity；另支持research_purchase、travel；不是自动认定费用合规 |
| OCR | `--with-ocr` | 默认不安装；显式选择本地或配置自己的远程提供方 |
| 帮助语言 | `guide(topic, language)` | zh或en，默认zh；不改案件数据 |
| 浏览器接线 | bridge预览→执行 | 本人现有Edge、当前用户、固定扩展；不复制会话 |
| 批次 | register_workflow预览→执行 | 明确案件、账号、计划及授权，必须复核预览SHA |

```sh
sh install.sh --data-dir "/绝对路径/报销资料" --profile-id project_alpha --title "项目甲" --mode student_activity
```

Windows使用`install.cmd --data-dir "D:/Reimbursement/materials" ...`。资料根绑定后重跑安装不会悄悄更换范围；缺失的旧规范库应先恢复，不能重置为空白来通过自检。

## 文件归属

| 文件/目录 | 由谁维护 | 是否可分发 |
| --- | --- | --- |
| `distribution/data/*`、requirements锁文件 | 公开源码及安装器 | 可以；只有空白/通用配置 |
| `.local/installation.json` | 本机安装器 | 不可以；含接收者的路径绑定 |
| `.local/client-configs/` | setup生成 | 不复制给其他电脑；在目标设备重新生成 |
| 资料根/规范库 | standards接口 | 私人规则；公开示例不含真实单位规则或人员 |
| `cases/` | 案件接口及用户确认 | 私人业务登记；不得作为开源默认值 |
| `.local/edge-bridge/` | 本机桥及安装器 | 不可以；保留请求和恢复证据，不手工清pending |
| `.local/ocr-provider.json` | OCR配置流程 | 不可以；远程节点/路径另行配置 |
| `.local/self-check-current.json` | 自检 | 仅本机导航，HTML/JSON报告路径可能含个人目录 |

不要编辑生成的installation.json来扩大授权范围。MCP和CLI共用安装绑定；显式`--material-root`覆盖应限当前已授权目录。不要把代码目录本身当作材料输出目录。`.local`根本身不得是链接或Windows重解析点；便携启动器也会检查内部运行时链接。Windows仅保留冻结Python次版本别名到同父目录完整版本实体目录的精确映射；其他重解析点、断链、链式及UNC/设备目标均拒绝。检查不沿别名遍历，实体目录仍正常遍历。手动创建、指向外部Python的开发环境不等于便携安装，保留它并在新目录安装便携包。

## AI接入

将`.local/client-configs/mcp.json`中这一项合并到自己的stdio MCP客户端，不覆盖其余服务。需要TOML的客户端使用同目录生成的片段，按其当前官方配置方式导入。配置里的解释器、脚本和资料根必须都是接收者本机路径。

```json
{"method":"guide","params":{"topic":"configuration","language":"en"}}
```

没有MCP也可使用`tools/reimbursement.cmd call --input 请求绝对路径`或`sh tools/reimbursement.sh call --input 请求绝对路径`。新用户说明与schema一致性由`tools/check_public_docs.py`检查；语言不是另一套业务实现。运行错误目前主要为中文，error_code、方法名和JSON键保持稳定。

## 财务专项

先`cases → overview`，然后读[整批流程](整批流程与登记.md)。本批账号与实际登录人必须一致。准备与本人批准分别授权；`show_verification_interface`默认false，只有明确true才在验证码停点置前显示原窗口。用户在官网填写验证码，不交给AI。

明细PDF输出根、列表格式及Edge实际下载目录分别配置。导出命名可明确下划线或空格，日期与序号来自已确认计划。未知事实、缺少真实准备回执、旧SHA或用户暂缓状态都不会因登记成功而消失。

## 安全与检查

安装器先检查运行目录边界，再校验下载。私有规范通过带SHA的接口更新；已有配置冲突时先核原记录，不强制覆盖。扫描/OCR只用已授权资料，文字层优先，不自动上传第三方服务。

Office/OFD XML统一拒绝实体和外部资源，限制XML为64MiB、深度128、节点500000，压缩包最多10000项/512MiB；超限需拆分来源，不静默截断。Poppler自身生成的XHTML可保留普通DOCTYPE，但实体与外部资源仍被禁止。

按[安全说明](../SECURITY.md)报告问题。配置正确、静态检查及依赖审计均有范围和时间边界，不代表所有网页版本、设备或真实业务都已验证。

XML运行时须为Expat 2.8.5或更新版本；语法兼容Python3.11以上不代表旧解释器已打安全补丁，推荐当前冻结Python3.12.15。

三种客户端片段（JSON、TOML、YAML）由同一绑定生成，自检逐份核对当前工具路径、资料根和参数；有一份缺失或改变即不报就绪。修改客户端全局配置不属于本地片段自检范围。
