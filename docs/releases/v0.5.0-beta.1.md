# v0.5.0-beta.1 · 测试版 / Prerelease

Windows真实财务流程尚未实测。本版供隔离安装、材料处理和接口试用；不能据此认定真实登录、验证码后接续、批量批准、明细PDF或列表导出已通过，也没有5分钟整批达标的实测结论。本次发布不操作真实单据。

The real Windows finance workflow has not been tested. This prerelease is for isolated installation, document processing and interface evaluation. It does not certify live login, verification-code continuation, batch approval, detail PDFs, native list exports or the five-minute batch target. No real financial documents are operated on as part of this release.

## English

Changes since v0.4.0-beta.1:

- Adds Windows batch registration, bridge setup and phase interfaces, sharing case, request-identity and original-task recovery contracts with macOS. Detail PDFs and native list exports remain separate actions. The owner enters verification codes on the official website.
- Adds bilingual deployment, configuration, policy, OCR, interface, maintenance and security guides. All 18 guidance topics support zh/en; CLI/JSON and stdio MCP share the service contract, with 50 MCP tools.
- Generates and checks JSON, TOML and YAML client fragments. Python and dependencies remain local to the installation; global Python and AI settings are unchanged. Local OCR is explicit opt-in; remote providers are separately configured.
- Pins Python 3.12.15, uv 0.13.5, Pillow 13.0.0 and OpenTelemetry API 1.45.1. Office/OFD XML now shares bounded parsing with entity/external-resource restrictions. Verified-source bytecode loading and runtime-link boundaries are hardened.
- Retains authorization-revocation, original-connection and cross-user task protections. Unknown finance outcomes require recovery of the original task, not resubmission under a new ID or deletion of pending evidence.

Validation scope: isolated macOS ARM64, Ubuntu x86_64 and Windows AMD64 CI covers fresh ZIP installation, offline checks, Python regression, three Node contract suites, actual stdio MCP, synthetic intake and CPU OCR. Windows includes the fixed internal Python alias and rejection of escaping, wrong-target, broken, chained and nested links. Another AI exercised the English CLI/MCP entry points. See [GitHub Actions](https://github.com/Rtiming/ustc-reimbursement/actions) for the exact commit; conditional skips are not passes.

Security evidence is scoped and dated: known-advisory checks for locked dependencies, sensitive-information scans of public source/history/package members, and targeted code review. See the [security review](https://github.com/Rtiming/ustc-reimbursement/blob/v0.5.0-beta.1/docs/en/security-review.md). This is not a guarantee that no vulnerabilities exist.

Download the attached `ustc-reimbursement-0.5.0-beta.1.zip` and `SHA256SUMS`, then verify SHA256. GitHub's automatic Source code ZIP is not the installation archive. After extraction, run `install.cmd` on Windows or `sh install.sh` on macOS/Linux. Add `--with-ocr` for local OCR or `--check` to check an installed environment. [English quick start](https://github.com/Rtiming/ustc-reimbursement/blob/v0.5.0-beta.1/README.en.md).

Upgrade into a new directory. Preserve the old installation, originals, private policies, cases and receipts; regenerate local configuration. Do not copy a venv, the whole .local tree or browser login databases. Resolve unknown outcomes in the original installation first. Existing 0.4 installations do not update automatically. Windows ARM64, macOS Intel, Linux ARM64 and optional external adapters are outside this complete CI matrix. Linux finance-browser operation is unsupported.
