# v0.6.1-beta.1 / Windows适配补齐

本版将Windows现场发现的通用缺口纳入正式接口：PowerShell带BOM的请求、Windows只读入口、证明人工号查询、同编码经费的负责人消歧、未分配科目的逐票减报、草稿与本人审核状态区分。实际代码不包含现场账号、审批人、材料或私人规则。

三系统发行验收扩展为全部已打包Node合同，与Python回归、新目录安装、自检、stdio MCP、原件归档及CPU OCR共同执行。精确提交的通过情况以本Release链接的Actions为准。

Windows已有旧版现场登录、填单、减报、薪酬和审批操作记录及用户反馈；本版不为发布而重办真实单据。旧版补丁现场、当前包合成验收与各设备真实业务验收分别记录。Windows ARM64、全部薪酬类别、所有付款方式及所有真实导出未逐项实机证明，不作5分钟整批性能承诺。

使用[Windows适配与功能验收](../Windows适配与功能验收.md)查看各功能入口、迁移和恢复。保留原安装、案件与任务；更新不清pending、不重放未知写入，也不迁移浏览器登录库。

## English

This prerelease incorporates reusable Windows field fixes into the supported interfaces: BOM-prefixed PowerShell requests, Windows read-only entry points, teacher lookup by confirmed staff ID, project-owner disambiguation, reductions before subject allocation, and draft/applicant-review state separation.

All packaged Node contracts now run on Windows, macOS and Linux alongside Python regression, fresh ZIP installation, self-checks, real stdio MCP, source-preserving intake and CPU OCR. Refer to the exact commit's Actions results linked from the release.

Historical Windows operations and user feedback cover login, draft preparation, reductions, remuneration and approvals using an older patched installation. They do not certify every action in this exact release. No real claim is resubmitted for release testing. Windows ARM64, every remuneration category, payment route and live export remain separately scoped; no five-minute performance claim is made. Keep existing cases and unknown-write receipts, and use the original recovery path.

Windows完整离线包的本机服务探测直接访问127.0.0.1，不借用户的外部HTTP代理；安装断网验证为回环地址保留直连。Node是源码开发合同测试的运行时，完整离线用户包不要求安装Node；缺少Node时对应测试明确跳过，三系统CI仍安装Node并执行这些合同。

Local workbench probes bypass external proxies. Node is a development contract-test runtime: its absence is reported as skipped on a user installation, while the three CI platforms install Node and retain the complete contract coverage.

Windows读取状态文件时可能短暂拒绝原子替换；桥在1秒预算内接续同一份冻结状态字节。持续权限错误仍停止，排他请求/意图仍禁止覆盖，登录与财务操作不重放。

The Windows bridge tolerates brief status-file sharing conflicts with a bounded retry of the same frozen local bytes. Persistent permission failures stop, exclusive intents cannot be overwritten, and no login or financial action is replayed.

同时缩短同目录状态临时文件名，修复未启用系统长路径的Windows设备在安装自检时先因临时后缀超过路径上限而失败的问题。
Compact same-directory temporary state filenames also prevent an otherwise valid Windows installation path from exceeding the legacy limit solely because of its temporary suffix.
