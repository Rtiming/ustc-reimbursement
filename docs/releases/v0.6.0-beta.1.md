# v0.6.0-beta.1 · 人工与agent统一工作台

本预发行将材料核对、规则、分单、填报准备、任务恢复和交付接到同一个本地工作台；人工界面、MCP和CLI共用案件、确认与回执。

- 固定启动入口，支持新活动、多活动收件、已有活动补件和关闭后续办。
- 从原件关联发票、申请额、实际收款、付款凭证和行程；机器候选须对照原件确认。
- 确认分单后生成同源本地子案；重复操作复用原结果，中断和范围冲突保留原意图。
- 逐页确认电子、纸质及排除去向，导出问题总结Excel和A4单面附件；共用付款只附一次，纸质原件只登记。
- compact工具集提供按操作发现、精确字段、准备、确认和原任务状态，保留完整MCP与CLI入口。
- Windows完整离线包包含固定Python和依赖，支持首装、重装、升级与回退。
- 保留既有双语指南、公开依赖安全检查、归档字节核验和原任务恢复约束。

验证包括独立Windows离线安装与升级回退、人工与agent交替处理合成材料、51票拆为26/25张本地子案及实际Excel/PDF下载。公开发行版本另运行macOS、Linux、Windows安装和OCR检查；最终状态以对应提交的CI及Release验收摘要为准。

软件安装、合成流程和学校实际办理分别验收。新电脑的Edge接线、本人账号、角色、经费、验证码及真实单据仍需现场核对；本次不宣称已获学校批准、已付款或达到真实批量审批耗时目标。私人规则、案件、账号和登录资料不在公共发行包中。

## English

This prerelease adds a local workbench shared by people and AI agents. It connects intake, evidence review, private rules, local case splitting, form preparation, recovery and delivery while retaining the same confirmation and receipt contracts.

The Windows offline bundle includes a pinned Python runtime and dependencies. Compact MCP tools provide action-specific schemas and resumable intents; full MCP and CLI remain available. Excel checklists and A4 attachments keep page provenance, include shared payment evidence once and record paper originals separately.

Independent Windows installation, upgrade/rollback and synthetic human/agent journeys were exercised. The public release also runs installation and OCR CI on macOS, Linux and Windows. School login, roles, funding, SMS verification and real financial actions require separate on-site acceptance. No private cases, rules or credentials are included.
