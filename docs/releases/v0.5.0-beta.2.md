# v0.5.0-beta.2

用户更新与部署稳定化测试版。新增update.sh/update.cmd：固定公开源查版本、SHA与完整清单核验、相邻新目录安装和可接续回执。新增固定字段部署文件与无副作用计划；修复自检参数位置导致意外进入下载链；成功部署绑定完整源码指纹，失败保留旧接受记录。原版目录、现有案件和未知动作原地保留。

这不是原地自动升级或案件迁移。新工作使用新入口与新MCP片段，旧案仍用旧目录。默认不增加本机OCR；已明确启用本机OCR的更新延续该选择。财务浏览器、跨设备或新权限没有因离线安装而被验收。

## English

User-update and deployment hardening prerelease. Adds fixed-source release checks, checksum and exact manifest validation, side-by-side installation, declarative deployment files and a read-only plan. Check flags no longer enter bootstrap due to argument order. Successful installation records its source fingerprint; failures preserve the previous accepted identity.

This does not replace an installation in place or migrate cases. Use the new entry/MCP fragment for new work and retain old paths for existing cases and unknown actions. It does not establish live finance acceptance or cross-device qualification.
