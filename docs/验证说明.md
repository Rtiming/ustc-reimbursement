# 验证范围

版本状态以[GitHub Actions](https://github.com/Rtiming/ustc-reimbursement/actions)对应提交的实际结果为准；存在工作流文件本身不代表已通过。

公开CI在macOS、Windows和Linux执行：构建发行ZIP、在新目录解压、一键安装、离线自检、公开合成回归、真实stdio MCP和材料归档。OCR安装分支使用合成图片进行实际CPU识别。失败会保留具体步骤，不把跳过当通过。

首版发布前，本地macOS已完成不使用作者Python环境的新用户安装，以及CLI、47个MCP工具发现、合成收件、专项规则维护和本地OCR。独立AI代理曾实际调用CLI/JSON完成新用户流程；这不代表每款AI客户端的界面配置均已实测。远程LinuxOCR已用配置提供方完成原生文字页跳过、扫描页识别与回接。

| 范围 | 证据边界 |
| --- | --- |
| 三系统安装与材料/OCR | 看对应提交的公开CI；只覆盖所列runner架构 |
| macOS Intel、Linux ARM64、Windows ARM64 | 有启动器目标，首版未逐台实测 |
| 学校财务浏览器 | 依赖本人账号和当前网站，CI不运行真实业务 |
| Windows登记整批工作页 | 尚未支持；已有部分桥接口不等于整批可用 |
| Linux财务网页 | 不支持 |
| 手机通道、远程总账、专有表格导出 | 需要自行配置提供方，不属于便携基础功能 |

OCR文字保留来源、页码和SHA；数字可能误识，不能自动升级为确认金额。真实历史整批批准未达到5分钟目标，本项目不作5分钟性能承诺，也不重复批准真实单据来造测试数据。
