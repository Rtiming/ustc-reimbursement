# 安全与隐私报告

支持范围为最新公开预发行版；财务网站变化、部署方式和第三方依赖可能影响行为。不要把未经验收的适配器用于真实写入。

涉及凭据泄漏、越权读取、重复提交或私人材料外发的问题，请使用仓库的[私密漏洞报告](https://github.com/Rtiming/ustc-reimbursement/security/advisories/new)。不要在公开Issue上传真实票据、身份证明、账号、Cookie、验证码或完整运行日志。

报告请提供版本、操作系统、合成复现步骤、预期行为和实际行为。敏感值删除后再附日志；不要为复现漏洞重复执行真实批准、删除或付款。

如果误公开了凭据，先在对应服务撤销或轮换，再联系维护者处理公开内容；仅删Git文件不能撤销凭据。

工具默认只通过stdio在本机提供MCP，不开放网络服务。执行范围来自明确资料根与案件，写操作保留原请求及独立回读；验证码始终本人填写。将本工具包装成网络服务时，身份、隔离、审计和AGPL源码提供义务由部署者负责。
